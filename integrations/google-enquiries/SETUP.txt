PARK EPP - Google Sheet, FormSubmit email and chatbot logs

The EPP homepage and contact forms, product quote forms, and completed chatbot enquiries
use the same Google Apps Script endpoint and Sheet. Enquiries are written to the Enquiries
tab first; the website sends the email through FormSubmit after the Sheet confirms success.
Each chatbot user and assistant message is also written to the Chat Logs tab with a session ID.

Default deployment:
https://script.google.com/macros/s/AKfycbzFzTpdcN-nm45LYeysTsBj3HEcUYT-BskK2Cv7SmAiMcp7ELS00txWFG2lBfiQdlC7/exec

Apps Script setup
1. Add this folder's Code.gs to the Google Sheet's Apps Script project.
2. Set Script Properties:
   ALLOWED_ORIGINS: exact permitted site origins, comma-separated.
   Include http://127.0.0.1:3000 for the local preview if needed.
   SHEET_ID is optional; Code.gs uses the PARK Sheet ID by default.
3. Deploy as a Web app, execute as the owner, and allow access to Anyone. Authorize Sheet access.
4. Set NEXT_PUBLIC_GOOGLE_ENQUIRY_URL only if using a different /exec deployment. Restart
   the dev server and rebuild/redeploy the website after changing this value.
5. Confirm FormSubmit is activated for sales@parknonwoven.com. Verify that a form enquiry
   reaches both Enquiries and the recipient inbox, and chatbot messages reach Chat Logs.

The Enquiries tab stores the contact details, product, query, website, page origin, status,
and requirement. Chat Logs stores session ID, received time, website, page origin, speaker,
and each message. Request IDs prevent duplicate enquiry rows on retries. FormSubmit sends
the EPP email after the Sheet write succeeds; the Apps Script itself does not send email.

Redeploy the updated Code.gs as a new Apps Script version before publishing the matching
frontend change.
